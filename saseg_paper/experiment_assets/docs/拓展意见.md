# 论文叙事升级：从医学 CT 到跨域 Dense Segmentation

## 1. 改动目的

本次叙事升级的核心目的是：

> 将论文从"腹部 CT 上的一个结构化弃权分割方法"升级为"在医学 CT 上提出、并在多个自然图像语义分割域中验证的 structured abstention 框架与现象研究"。

已完成的 VOC2012 与 Cityscapes 跨域实验证明，论文的两条核心现象不依赖于医学成像特性：

1. **native unknown slots 的必要性跨域成立**：去掉 unknown slots 后，unknown F1 在 VOC 和 Cityscapes 上均崩塌超过 96%，即便 MSP 的 AUROC 仍保持在 0.93 以上
2. **detection-structuring gap 跨域成立**：VOC 和 Cityscapes 的 ensemble AUROC 均超过 0.95，但 unknown F1 接近零，与 Synapse/AMOS22 的模式完全一致

这两条结论使论文具备了更强的说服力：这些不是腹部 CT 偶然现象，而是 dense segmentation 领域的通用性质。

## 3. 改动后的论文定位

### 标题

`Structured Abstention Segmentation: Native Unknown Representation for Open-World Dense Prediction`

### 贡献口径

| 贡献 | 改动前 | 改动后 |
|------|--------|--------|
| 问题定义与评测协议 | 医学图像语义分割 | Dense segmentation（以医学 CT 为首要场景） |
| M=0 必要性验证 | Synapse + AMOS22 两数据集 | Synapse + AMOS22 + VOC + Cityscapes 四数据集 |
| Detection-structuring gap | Synapse + AMOS22 | 四数据集，跨三个视觉域 |

### 叙事结构

论文的叙事流保持为：

1. 以医学 CT 的 clinical safety 为出发动机
2. 提出 structured abstention 问题定义与 A1/A2 双协议（domain-agnostic）
3. 在 Synapse/AMOS22 上完整验证方法与现象（主线不变）
4. 在 VOC/Cityscapes 上做最小闭环跨域验证，证明现象的通用性
5. 结论落在"structured abstention 是 dense segmentation 的通用挑战"

### 不成立的口径（改动后仍不写）

- "SASeg 在自然图像上是 SOTA"
- "本文提出一个通用语义分割方法"
- "A1/A2 已经统一解决 open-world segmentation"

跨域实验强化的是**现象定义的普遍性**，不是方法的横向竞争力。
